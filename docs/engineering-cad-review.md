# Краткий обзор CAD-подходов для AoSCAD Studio

Обзор выполнен по открытым описаниям и исходным репозиториям проектов; это выборка практических принципов, а не сравнение возможностей по маркетинговым материалам.

| Программа / проект | Полезный для AoSCAD подход | Вывод для отдельного приложения |
|---|---|---|
| [FreeCAD](https://github.com/FreeCAD/FreeCAD) | Параметрические объекты, история модели и переход от эскиза к 3D. Проект построен на Open CASCADE и Qt. | Сохранять параметры рядом с BREP-геометрией и позволить менять размеры созданных объектов без повторного импорта. |
| [SolveSpace](https://github.com/solvespace/solvespace) | Параметрическое 2D/3D-проектирование с ограничениями и решателем. | Эскизы с ограничениями — важный следующий этап, но не стоит имитировать их без геометрического решателя. |
| [OpenSCAD](https://github.com/openscad/openscad) | Явные числовые параметры и последовательное построение тела из примитивов и операций CSG. | Сделать размеры примитивов видимыми и редактируемыми; это небольшое, проверяемое развитие текущего BREP-редактора. |
| [LibreCAD](https://github.com/LibreCAD/LibreCAD) | Отдельное настольное CAD-приложение; практичная ориентация на обмен DXF и пакетные преобразования. | Поддерживать AoSCAD как самостоятельную программу и явно объяснять границы обменных форматов. |
| [KiCad](https://github.com/KiCad/kicad-source-mirror) | Проектный подход с несколькими специализированными редакторами и отдельным 3D-просмотром. | Сохранять связанное состояние проекта и геометрию вместе; не смешивать CAD-модель с произвольными временными данными. |
| [Open CASCADE Technology](https://github.com/Open-Cascade-SAS/OCCT) | Геометрическое ядро для 3D-моделирования, обмена CAD-данными и визуализации; используется в C++-приложениях. | Продолжать использовать OCCT для BREP, STEP/IGES и расчёта площадей, объёмов и габаритов. |

## Принятые решения

1. AoSCAD Studio остаётся самостоятельным нативным приложением на C++ / Qt / Open CASCADE, а не дополнением для другой CAD-системы.
2. Для локальных примитивов добавлены редактируемые параметры и сохранение их вместе с точной BREP-геометрией. Формат проекта `.aoscad` обновлён до версии 3; проекты версии 2 продолжают открываться.
3. Инспектор показывает площадь, объём, габариты и оценку массы по выбранному материалу. Масса помечается как оценочная; для открытой сетки объём может быть недоступен.
4. Для SolidWorks, T-FLEX CAD и других систем сохраняется нейтральный путь обмена через STEP AP214/AP242 или IGES. Нативные проприетарные форматы не заявляются как поддерживаемые.
5. Эскизный решатель, история операций произвольной глубины, булевы операции, сборки и конструкторские чертежи не входят в эту итерацию: они требуют полноценной параметрической модели, а не только UI-обёртки над BREP.
6. Обновление поставляется отдельной небольшой Windows-программой. Она скачивает опубликованный установщик с GitHub Releases и проверяет его SHA-256 по release-манифесту; при запуске из AoSCAD Studio ждёт закрытия приложения перед тихой установкой.
