# AoSCAD Studio

Самостоятельная CAD-среда для просмотра, подготовки и обмена 3D-геометрией. Есть браузерный режим разработки и настольная сборка Windows. Ориентир — [AeroS Engine](https://github.com/cumaktimur490-arch/Aeros-Engine): подготовьте модель в AoSCAD, экспортируйте STL и откройте его в Aeros Engine для аэродинамической визуализации.

## Возможности
- 3D-сцена, дерево компонентов, выбор/скрытие/переименование, перемещение, вращение и масштабирование.
- Примитивы, простой эскиз XY, измерение расстояния, материалы и локальное автосохранение.
- Импорт STEP/STP, IGES/IGS и BREP через OpenCascade WebAssembly; STL, OBJ, PLY, 3MF, GLB/GLTF, DXF и AoSCAD project.
- Экспорт STL, OBJ, GLB, DXF (эскизные линии) и собственного проекта `.aoscad`.
- В настольной версии импорт и экспорт файлов остаются локальными; файлы пользователя не загружаются на сервер.

## Создание установщика Windows

Установщик — NSIS-пакет x64 с ярлыками в меню «Пуск» и на рабочем столе. Цифровая подпись сертификатом издателя пока не настроена, поэтому Windows SmartScreen может показать предупреждение о неизвестном издателе.

**Локально на Windows 10/11:**
```bash
npm ci
npm run release:win
```
Файл появится в `release/AoSCAD-Studio-Setup-0.1.0-x64.exe`.

**GitHub Actions:** workflow `Windows installer` можно запустить вручную из Actions — установщик появится в артефактах сборки. После публикации GitHub Release workflow соберёт `.exe` на Windows runner и приложит его к релизу. Для первой версии создайте релиз `v0.1.0` (версия из `package.json`).

Для локальной отладки настольной оболочки: `npm run app:dev`. Браузерная разработка: `npm ci` и `npm run dev`.

## SolidWorks, T-FLEX и другие CAD
Внутренние файлы SolidWorks (`.SLDPRT`, `.SLDASM`) и T-FLEX напрямую не читаются: форматы проприетарны. Откройте модель в исходной CAD-системе и экспортируйте в **STEP AP214/AP242** либо **IGES**, затем импортируйте сюда. STEP/IGES геометрия триангулируется в сетку: BREP-топология и история параметрических операций не сохраняются. Обратный экспорт STEP/IGES пока не реализован. Для Aeros Engine экспортируйте STL.

## Сборка веб-версии
Требуется Node.js 20+.
```bash
npm ci
npm run dev
```
Сборка: `npm run build`; просмотр сборки: `npm run preview`.

## Управление
`Q/W/E/R` — выбор/перемещение/вращение/масштаб; `F` — вписать модель; `Delete` — удалить; `Ctrl+Z`, `Ctrl+Shift+Z` — отмена/повтор; `Ctrl+S` — сохранить проект. Средняя кнопка мыши — орбита, правая — панорамирование, колесо — масштаб.

Стек: Three.js, Vite, Electron, OpenCascade `occt-import-js` (WASM). Лицензии зависимостей см. в пакетах.
