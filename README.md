# AoSCAD Studio

Самостоятельная настольная CAD-среда. Основная реализация — C++17, Qt 6 и Open CASCADE; это отдельное приложение, а не плагин для другой CAD-системы.

## Параметрическое CAD MVP

Нативный C++ клиент теперь включает этап 1 Sketch → Extrude: безопасные формулы/переменные, базовые прямоугольный и круглый эскизы на XY/YZ/ZX, параметрические размеры и Extrude с полупрозрачным предпросмотром и подтверждением/отменой. Архитектура, ограничения текущего solver и четырёхэтапная дорожная карта описаны в [`docs/cad-mvp-architecture.md`](docs/cad-mvp-architecture.md).

## Что реализовано в нативной C++ версии

- 3D-вид с орбитой, панорамированием, масштабом и стандартными видами; выбор объектов мышью.
- Примитивы: бокс, цилиндр, сфера, конус и тор. Их исходные размеры редактируются параметрически; трансформации выполняются мышью или через свойства.
- Эскиз прямоугольника/окружности на выбранной плоскости XY/YZ/ZX; базовые привязки к началу координат и сетке 5 мм, осевые стороны и замкнутый прямоугольный профиль.
- Менеджер переменных и формул: `L = 120`, `W = L/2`, скобки и `sin/cos/sqrt/min/max`; обнаружение неизвестных имён, циклов и неконечных результатов. Длины формул задаются в миллиметрах.
- Параметрическое Extrude создаёт точную OCCT B-Rep форму. Динамическое поле длины/симметрии показывает полупрозрачный preview; «Применить» записывает фичу в дерево, «Отмена» не меняет документ.
- Дерево компонентов, скрытие объектов, цвет, единицы мм/см/дюйм, отмена и повтор. Есть команды «Сохранить» / «Сохранить как…», привязка проекта к файлу и подтверждение перед потерей несохранённых изменений.
- Инспектор показывает площадь, объём, габариты и расчётную массу выбранного материала (сталь, алюминий, медь, ABS, PLA и др.).
- Импорт STEP/STP, IGES/IGS, BREP, STL и OBJ через Open CASCADE.
- Экспорт STEP, IGES, BREP, STL и OBJ; проект `.aoscad` сохраняет BREP-геометрию, формулы/переменные, UUID фич, входные ссылки и материалы.
- Инструмент измерения расстояния. Для Aeros Engine предусмотрен экспорт STL.
- В меню «Справка» доступна проверка обновлений. Отдельный Windows updater загружает установщик из GitHub Releases, проверяет SHA-256 и ждёт закрытия AoSCAD перед установкой.

Проект `.aoscad` сохраняется в формате версии 4 и продолжает открывать нативные версии 2 и 3. B-Rep для параметрических фич перестраивается из сохранённых формул; история undo/redo пока остаётся только в памяти. Старые сборки, знающие только v2/v3, не должны перезаписывать v4.

Для тестов используйте `ctest --test-dir build --output-on-failure` после сборки. Текущий Sketcher ограничен прямоугольником/окружностью и базовыми привязками; полноценный constraint solver, устойчивые ссылки на топологию, смещение грани и фоновый пересчёт запланированы отдельно.

## Сборка C++ приложения

Нужны CMake 3.22+, C++17, Qt 6.5+ (Core, Gui, Widgets, OpenGL, OpenGLWidgets) и Open CASCADE с модулями обмена STEP/IGES и STL. На Windows дополнительно собирается нативный updater на системных Win32/URLMon/CNG API.

### Windows с vcpkg

В репозитории есть `vcpkg.json` с зависимостями Qt и Open CASCADE. В PowerShell, из каталога репозитория:

```powershell
cmake -S . -B build `
  -DCMAKE_TOOLCHAIN_FILE="$env:VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake"
cmake --build build --config Release
```

Запускаемый файл появится в `build/Release/aoscad-studio.exe` (или `build/aoscad-studio.exe`, в зависимости от генератора CMake).

### Windows Release installer

Публикация GitHub Release запускает workflow `Windows C++ installer`: он собирает приложение и updater для Windows 10 x64 (минимум Windows 10 version 1809), разворачивает Qt/Open CASCADE runtime, создаёт per-user установщик и прикладывает к релизу версионный и `Latest` установщики, standalone updater и SHA-256-манифест. Версия Inno Setup берётся из `CMakeLists.txt`, чтобы метаданные и имена файлов совпадали. Установщик и updater пока не подписаны сертификатом издателя, поэтому Windows SmartScreen может показать предупреждение.

### Linux / macOS или ручная установка библиотек

Установите Qt 6 и Open CASCADE development packages, затем укажите CMake пути к ним при необходимости:

```bash
cmake -S . -B build \
  -DCMAKE_PREFIX_PATH="/path/to/Qt;/path/to/OpenCASCADE"
cmake --build build --config Release
```

CMake target: `aoscad-studio`.

## Совместимость SolidWorks, T-FLEX и других CAD-систем

Нативные файлы SolidWorks (`.SLDPRT`, `.SLDASM`) и T-FLEX (`.TFC`, `.GRB`) напрямую не читаются: их форматы проприетарны. Экспортируйте модель из исходной программы в **STEP AP214/AP242** или **IGES**, затем откройте её здесь. Эти форматы предназначены для обмена между CAD-системами; при экспорте в STL/OBJ передаётся только полигональная сетка, без параметрической истории.

Для Aeros Engine экспортируйте STL и импортируйте его там. AoSCAD не заменяет расчёт аэродинамики в Aeros Engine.

## Примечание о переходе

Каталоги `src/`, `electron/` и файлы npm оставлены как прежняя браузерная/Electron реализация. Нативная C++ сборка запускается через CMake; Windows workflow собирает её и создаёт Inno Setup installer. Старый релиз `v0.1.0` относится к Electron-версии. Старые `.aoscad`-проекты из Web/Electron-версии пока не переносятся напрямую: откройте их в прежней версии и экспортируйте геометрию в STL или OBJ.
